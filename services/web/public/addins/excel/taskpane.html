Tributary

Figures from SEC filings in your cells, each with the filing it came from.

Your API key

Looking for a saved key…

Make one in Tributary's Settings, API keys: a read-only key is enough. It stays in this add-in's storage on this computer and goes only to Tributary.

Figures

Figures are kept for ten minutes; Refresh asks again for every cell. A workbook's cells go in requests of up to 200 figures, each counting once against the key's limits.

Functions

=TRIBUTARY.VALUE("NVDA", "revenue")
The newest quarter's figure. Then, optional: the period (latest, TTM, FY, FY2024, FY2024 Q3, CY2024 Q3 or a quarter's end day), an as-of day, and the currency you accept.
=TRIBUTARY.SERIES("NVDA", "revenue", 8)
The newest eight periods, oldest first: the period and the figure on each row. Then the span: quarter, TTM or FY.
=HYPERLINK(TRIBUTARY.SOURCE("NVDA", "revenue"))
The filing on EDGAR. Or a field: period, filed, form, accession, unit, status, reason.

#N/A with a reason means no number to show: stale, n/m, n/a, another currency (Tributary never converts: give the currency to read it) or nothing on file. #VALUE! is an argument to fix. More on the API
